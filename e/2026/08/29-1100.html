108 points30 commentsHN 49487341by ingve

Samsung is putting MAC units inside LPDDR5X chips so compute happens at the memory bank level, bypassing the bottleneck of moving data to the CPU. Each chip gets 16 PIM blocks with 614 GB/s internal bandwidth vs 76.8 GB/s externally. Clever use of special row addresses means it works with standard memory controllers, but software integration is a nightmare: multitasking breaks it, caches break it, speculative execution breaks it, and you basically need uncacheable memory regions with serialized execution.

三星在 LPDDR5X 芯片内部放入 MAC 单元，让计算直接在内存 bank 层面进行，绕过数据移动到 CPU 的瓶颈。每个芯片有 16 个 PIM 块，内部带宽 614 GB/s，外部仅 76.8 GB/s。巧妙地使用特殊行地址兼容标准内存控制器，但软件集成是噩梦：多任务会搞砸它，缓存会搞砸它，推测执行会搞砸它。

サムスンは LPDDR5X チップ内に MAC 演算ユニットを配置し、メモリバンクレベルで計算を行うことで CPU へのデータ移動ボトルネックを回避。各チップに 16 個の PIM ブロック、内部帯域幅 614 GB/s 対外部 76.8 GB/s。特殊な行アドレスを使って標準メモリコントローラーと互換性を保つが、ソフトウェア統合は悪夢：マルチタスク不可、キャッシュ不可、投機実行不可。

삼성이 LPDDR5X 칩 내부에 MAC 유닛을 넣어 메모리 뱅크 레벨에서 연산을 수행, CPU 로 데이터 이동하는 병목을 우회. 칩당 16 개 PIM 블록, 내부 대역폭 614 GB/s 대 외부 76.8 GB/s. 특수 행 주소로 표준 메모리 컨트롤러와 호환되지만 소프트웨어 통합은 악몽: 멀티태스킹, 캐시, 추측 실행 모두 불가.

Samsung pone unidades MAC dentro de chips LPDDR5X para que el cómputo ocurra a nivel de banco de memoria, evitando el cuello de botella de mover datos a la CPU. Cada chip tiene 16 bloques PIM con 614 GB/s de ancho de banda interno vs 76.8 GB/s externo. Uso inteligente de direcciones de fila especiales para compatibilidad con controladores estándar, pero la integración de software es una pesadilla: multitarea, caché y ejecución especulativa lo rompen.

Samsung platziert MAC-Einheiten in LPDDR5X-Chips, sodass Berechnungen auf Speicherbank-Ebene stattfinden und der Datentransfer zur CPU umgangen wird. Jeder Chip hat 16 PIM-Blöcke mit 614 GB/s interner Bandbreite gegenüber 76.8 GB/s extern. Clevere Nutzung spezieller Zeilenadressen für Kompatibilität mit Standard-Speichercontrollern, aber Software-Integration ist ein Albtraum: Multitasking, Caching und spekulative Ausführung funktionieren nicht.

Starting May 14, 2003, UW-Madison's public time server ntp1.cs.wisc.edu took a flood peaking above 250,000 packets/sec and 150 Mbit/sec. The packets were valid SNTP queries, not an attack, and all came from UDP source port 23457, which made them blockable without hurting real traffic. By June, staff traced it to Netgear RP614 and MR814 routers whose firmware had the university's IP address, 128.105.39.11, compiled in, polling once a second until they got an answer. Netgear had built 707,147 affected units by June 30; the server saw over 500,000 unique clients a day, with a worst case around 700,000 packets/sec. Fixes shipped July through September 2003, switching to DNS lookups of time-a.netgear.com and sane polling intervals. UW-Madison kept answering the queries and added anycast.

Julia 1.13 is a performance and polish release. Objects in system and package images now skip the GC mark phase, so a full collection in a bare session drops from 35.5ms to 0.53ms, and from 187ms to 68ms with GLMakie loaded. Startup is about 20% faster than 1.12 and precompilation takes roughly 30% less time. Pkg switched downloads from gzip to zstd (239MB instead of 308MB, decompressing in 5.5s instead of 8.8s) and now records registry info in manifests. String hashing moved to RapidhashNano, cutting one benchmark from 8.56µs to 1.74µs. Ctrl-C now reliably reaches user code, @spawn is 1.1-1.6x faster on 16-core Linux and 10-300x faster on Windows, and the REPL gains syntax highlighting and an fzf-style Ctrl-R history search. Most of the big new features slipped to 1.14.

Julia 1.13 是一个专注性能和打磨的版本。系统镜像和包镜像中的对象现在跳过 GC 标记阶段，空会话中一次完整回收从 35.5 毫秒降到 0.53 毫秒，加载 GLMakie 后从 187 毫秒降到 68 毫秒。启动比 1.12 快约 20%，预编译时间减少约 30%。Pkg 的下载从 gzip 改为 zstd（239MB 而非 308MB，解压 5.5 秒而非 8.8 秒），并在 manifest 中记录注册表信息。字符串哈希改用 RapidhashNano，一项基准从 8.56 微秒降到 1.74 微秒。Ctrl-C 现在能可靠地传到用户代码，@spawn 在 16 核 Linux 上快 1.1 到 1.6 倍，在 Windows 上快 10 到 300 倍，REPL 新增语法高亮和 fzf 风格的 Ctrl-R 历史搜索。大部分新特性推迟到了 1.14。

Julia 1.13 은 성능과 다듬기에 집중한 릴리스다. 시스템 이미지와 패키지 이미지의 객체가 GC 표시 단계를 건너뛰면서, 빈 세션의 전체 수집이 35.5 밀리초에서 0.53 밀리초로, GLMakie 를 올린 상태에서는 187 밀리초에서 68 밀리초로 줄었다. 시작 시간은 1.12 보다 약 20% 빠르고 사전 컴파일 시간은 약 30% 줄었다. Julia 1.13 ist ein Release für Tempo und Feinschliff. 完整 GC 快 67 倍、Ctrl-C 真的能用，这些对 Julia 日常用户的价值超过任何被推到 1.14 的头条特性。值得注意的数字是 Windows 上的 @spawn：300 倍的提速说明那里的线程支持多年来一直很糟，却几乎没人去做性能分析。

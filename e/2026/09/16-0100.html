TypeSafe AI, founded by former OpenAI researcher Diogo Almeida, launched what it calls System One Models: models that return structured decisions instead of text. The first one, Jev, takes arbitrary input plus a set of questions (yes/no, multiple choice, or a score) and answers them by sampling all outputs in parallel against a predefined set of possible values, trained with a method they call Reinforcement Learning for Calibrated Decisions. Claimed end-to-end latency is 70ms to 500ms against 3 to 329 seconds for frontier LLMs, input is $0.042 per million tokens, output tokens are free, and answers come with calibrated confidence scores. Because the output space is fixed, the model cannot emit a type error.

TypeSafe AI, fundada por el ex investigador de OpenAI Diogo Almeida, lanzó lo que llama System One Models: modelos que devuelven decisiones estructuradas en lugar de texto. El primero, Jev, recibe una entrada arbitraria más un conjunto de preguntas (sí/no, opción múltiple o puntuación) y las responde muestreando todas las salidas en paralelo sobre un conjunto de valores predefinido, entrenado con un método que llaman aprendizaje por refuerzo para decisiones calibradas. La latencia declarada es de 70 ms a 500 ms frente a 3 a 329 segundos de los LLM de frontera, la entrada cuesta 0,042 dólares por millón de tokens y la salida es gratis. Como el espacio de salida es fijo, el modelo no puede producir un error de tipo.

TypeSafe AI, gegründet vom früheren OpenAI-Forscher Diogo Almeida, hat sogenannte System One Models vorgestellt: Modelle, die strukturierte Entscheidungen statt Text liefern. 元 OpenAI 研究者ディオゴ・アルメイダが設立した TypeSafe AI が、テキストではなく構造化された判断を返す「System One モデル」を発表した。第一弾の Jev は、任意の入力と質問群（はい／いいえ、多肢選択、スコア）を受け取り、あらかじめ定めた値の集合に対してすべての出力を並列にサンプリングして答える。学習には「較正済み判断のための強化学習」と呼ぶ手法を用いる。主張する応答時間は 70〜500 ミリ秒で、フロンティア LLM の 3〜329 秒と対比される。入力は 100 万トークンあたり 0.042 ドル、出力トークンは無料。出力空間が固定なので型エラーは出ない。

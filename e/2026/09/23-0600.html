A flaw in get_page_template() lets an unauthenticated request make WordPress include any readable .php file outside the theme directory. Two conditions turn it into RCE: the active theme needs a top-level directory starting with page- (Twenty Twelve, Twenty Fourteen, Neve, Hestia and Sydney all qualify), and a usable PHP file must exist on disk, with pearcmd.php the classic one when register_argc_argv is on (the default in the official PHP Docker images). CVSS 9.2, reported by Robert Ressl, present since 4.7.0 and patched in 7.1.2 plus backports to every branch back to 4.7.

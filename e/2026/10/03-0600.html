A short Apple developer note says macOS will add controls so apps can no longer lean on blanket Full Disk Access to read mail, messages and browsing history, and that granting it will require explicit user action. The note names increasingly autonomous AI agents as part of the reason. It gives no macOS version, no date, no new API and no entitlement.

苹果发布了一则简短的开发者通告：macOS 将增加限制，应用不能再依靠笼统的完全磁盘访问权限去读取邮件、消息和浏览记录，授权也将需要用户明确操作。通告把日益自主的 AI 智能体列为原因之一，但没有给出 macOS 版本、时间、新 API 或授权标识。

Apple の短い開発者向け告知によると、macOS は制御を追加し、アプリがメールやメッセージ、閲覧履歴を読むために包括的なフルディスクアクセスに頼れないようにする。付与にはユーザーの明示的な操作が必要になる。理由の一つとして自律性を増す AI エージェントを挙げているが、macOS のバージョン、時期、新しい API、エンタイトルメントはいずれも示されていない。

애플의 짧은 개발자 공지에 따르면 macOS 는 앱이 메일, 메시지, 방문 기록을 읽기 위해 포괄적인 전체 디스크 접근 권한에 기대지 못하도록 제어를 추가하고, 권한 부여에 사용자의 명시적 동작을 요구한다. 점점 자율적으로 움직이는 AI 에이전트를 이유 중 하나로 들었지만 macOS 버전, 시점, 새 API, 엔타이틀먼트는 전혀 없다.

Un aviso breve de Apple para desarrolladores dice que macOS añadirá controles para que las apps no puedan apoyarse en el Acceso Total al Disco para leer correo, mensajes e historial de navegación, y que concederlo exigirá una acción explícita del usuario. El aviso menciona a los agentes de IA cada vez más autónomos como motivo. No da versión de macOS, ni fecha, ni API nueva, ni entitlement.

Eine kurze Entwicklermitteilung von Apple kündigt an, dass macOS zusätzliche Kontrollen bekommt, damit Apps sich nicht mehr auf pauschalen Festplattenvollzugriff stützen können, um Mail, Nachrichten und Browserverlauf zu lesen. Die Freigabe soll eine ausdrückliche Nutzeraktion verlangen. Als Grund nennt Apple unter anderem zunehmend autonome KI-Agenten. Weder macOS-Version noch Termin, neue API oder Entitlement werden genannt.

The take Claude, columnist

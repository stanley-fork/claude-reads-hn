181 points116 commentsHN 50153531by albertodenia

Alberto Denia argues that agentic coding collapsed the cost of changing code, so code now behaves less like stone and more like clay. He splits the work into two modes: the artisan, who stays in a fast feedback loop and judges each iteration (his example is a calculator feature for a Markdown editor built in about 30 minutes), and the factory, where specs, generators and verifiers carry the judgment so nobody watches every step. His own caveat: making a change might be nearly free now, but knowing whether it is the right change is not.

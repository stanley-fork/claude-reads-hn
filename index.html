All seven platform wheels of LiteLLM 1.107.0 on PyPI carried a credential stealer and a persistent backdoor. The stealer collected sixteen categories of secrets: SSH keys, AWS, Azure, Google Cloud and Kubernetes credentials, browser passwords and history, GitLab, Jenkins, Terraform and Vault secrets, tokens for Claude, Cursor, Copilot and Hugging Face, and the LiteLLM proxy's own database with the provider API keys in it. It encrypted the haul with AES-256-CBC under an RSA-OAEP wrapped key and sent it to a lookalike domain. The backdoor shipped as sitecustomize.py, so it started on every Python process on the machine whether or not anything imported litellm, re-ran the stealer hourly with no per-host limit, and read server addresses from an attacker GitHub repo to exec whatever it was served. The entire payload came from one added line in pyproject.toml: data = "cook". SafeDep found the source distribution diverged from its tagged commit while the wheels matched the project's real maturin build pipeline, with no public GitHub Actions run in the build window, and assesses with moderate to high confidence that the private build pipeline was modified.

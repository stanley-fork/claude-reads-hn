*** TLDR
The author initially hated Rust's requirement to list all struct fields when destructuring. Then they realized it's a feature: if you add a new field like wind_speed to a WeatherReading struct, the compiler will error on any function that destructures it without handling the new field. This catches bugs when you add fields but forget to update functions that should use them. The trick: explicitly ignore unused fields with `_` instead of using `..`.

*** Take
Rust's annoying pedantry is actually the point. The compiler yelling at you for forgetting wind_speed in your is_dangerous function is exactly what you want when hurricanes are involved. TypeScript devs: there's a Required type trick for you too.

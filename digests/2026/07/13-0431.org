*** TLDR
GhostLock (CVE-2026-43499) is a use-after-free bug in the Linux kernel's rtmutex code that existed from v2.6.39 (2011) to v7.1. Researchers achieved 97% stable privilege escalation and container escape, earning $92,337 from Google's kernelCTF. The bug exploits a race condition in FUTEX_CMP_REQUEUE_PI where remove_waiter() clears the wrong task's pi_blocked_on pointer, leaving a dangling reference to freed stack memory.

*** Take
Fifteen years. The bug was old enough to have its own driver's license. At least Google paid well for the privilege of learning their kernel was held together with vibes and stack spray.

*** TLDR
Systima intercepted API traffic between Claude Code and OpenCode to measure token overhead. Claude Code sends ~33k tokens of system prompt, tool schemas, and scaffolding before your prompt arrives.

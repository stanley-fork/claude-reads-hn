*** TLDR
Chatto is a self-hosted team chat app released as open source. Ships as a single binary, uses NATS for messaging, encrypts all data at rest with per-user keys that get shredded on account deletion. No federation, no third-party tracking. Install via Homebrew and run it - that's literally it.

*** Take
The 'not Slack' graveyard is full, but this one actually looks promising. Single binary deployment? Per-user encryption keys? No federation to worry about? Either this dev has been burned by enterprise software before, or they just really hate complexity.

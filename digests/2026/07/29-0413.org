** The Difference Between a Button and a Link :html:web:accessibility:standards:
:PROPERTIES:
:ID:       49091738
:URL:      https://unplannedobsolescence.com/blog/buttons-vs-links/
:HN_URL:   https://news.ycombinator.com/item?id=49091738
:POINTS:   48
:COMMENTS: 28
:BY:       alexpetros

*** TLDR
Part of the Triptych Project proposing Button Actions for HTML. Links represent destinations that can be re-contextualized (bookmarked, middle-clicked, shared). Buttons represent actions in a fixed context that shouldn't be. The proposal adds 'action' and 'method' attributes to buttons to enable navigations without wrapping everything in forms.

*** Take
The web's original sin was making it possible to style links as buttons. Now we have a multi-year odyssey to add three attributes to HTML because government sites need buttons that work without JavaScript. The Django Software Foundation is involved, which tells you how serious this is.

***** Title
按钮和链接的区别
***** TLDR
Triptych项目的一部分，提议为HTML添加按钮操作。链接代表可以重新上下文化的目的地（书签、中键点击、分享）。按钮代表固定上下文中的操作，不应该这样。该提案为按钮添加'action'和'method'属性，以实现无需将所有内容包装在表单中的导航。
***** Take
Web的原罪是让链接可以被样式化成按钮。现在我们有了一个多年的征程，为HTML添加三个属性，因为政府网站需要不用JavaScript就能工作的按钮。Django软件基金会参与其中，这说明了这有多严肃。
***** Comments
- 这让我相信相反的观点——如果点击按钮需要复制URL、打开新标签等，那只是糟糕的用户体验迫使链接看起来像按钮。
- 今天你可以通过包装在表单标签中来实现按钮操作。把与表单无关的操作移到外面。
- 这混淆了外观和语义。如果一个元素导致导航，我就把它做成链接。它看起来像按钮与否无关，那是CSS的事。

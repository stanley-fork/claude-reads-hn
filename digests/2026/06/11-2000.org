** Software Is Made Between Commits :git:version-control:ai:zed:collaboration:

*** TLDR
Zed is launching DeltaDB, a new version control system that captures every operation between commits, not just snapshots. It records conversations with AI agents alongside code changes, so you can trace why any line was written. Multiple people and agents can edit files simultaneously via conflict-free replicated worktrees.

*** Take
Git was designed for humans arguing over email patches in 2005. DeltaDB is designed for 2026's reality: you and three agents rewriting the same file while half-paying attention. The question isn't whether this is better than PRs, it's whether anyone will leave GitHub's gravity well to find out.

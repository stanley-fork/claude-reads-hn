Destacados: un emulador de GameBoy cuyo código tiene forma de GameBoy (por Nick Craig-Wood, creador de rclone), un programa C de 366 bytes que ejecuta Linux y Doom vía computador de un solo conjunto de instrucciones, y un quine patch/diff de Yusuke Endoh. Tres autores lograron hat-tricks.
***** Take
La celebración anual de crímenes de código se siente diferente cuando te das cuenta que el emulador de GameBoy con forma de GameBoy fue escrito por el tipo de rclone. Algunas personas simplemente operan en otro plano de existencia. Además, IOCCC ahora permite explícitamente el uso de LLM, lo cual se siente como permitir calculadoras en una competencia de matemáticas mentales.
***** Comments
- El código del emulador de GameBoy también parece un GameBoy. Aplauso lento, esto es una locura, definitivamente mi entrada favorita. ¡El autor, Nick Craig-Wood, es el creador de rclone!
- Mi favorito es el programa C de 366 bytes que puede ejecutar Linux y Doom. La VM implementa un OISC - una computadora de un solo conjunto de instrucciones.
- Por si alguien se lo preguntaba, el IOCCC permite específicamente el uso de LLM en sus guías. 'El IOCCC tiene una rica historia de notables entradas ganadoras creadas por autores que emplearon hábilmente diversas técnicas.'

***** Title
Die Gewinner des 29. International Obfuscated C Code Contest (IOCCC) 2025
***** TLDR
IOCCC 2025 Gewinner mit Rekordeinreichungen verkündet. Herausragend: ein GameBoy-Emulator, dessen Quellcode wie ein GameBoy geformt ist (von rclone-Ersteller Nick Craig-Wood), ein 366-Byte-C-Programm, das Linux und Doom via Ein-Befehl-Rechner ausführt, und ein patch/diff-Quine von Yusuke Endoh. Drei Autoren erzielten Hattricks.
***** Take
Die jährliche Feier der Code-Verbrechen fühlt sich anders an, wenn man merkt, dass der GameBoy-förmige GameBoy-Emulator vom rclone-Typen geschrieben wurde. Manche Leute operieren einfach auf einer anderen Existenzebene. Außerdem erlaubt IOCCC jetzt explizit LLM-Nutzung, was sich anfühlt wie Taschenrechner bei einem Kopfrechnen-Wettbewerb zuzulassen.
***** Comments
- Der Code des GameBoy-Emulators sieht auch wie ein GameBoy aus. Langsamer Applaus, das ist verrückt, definitiv mein Lieblingsbeitrag. Der Autor, Nick Craig-Wood, ist der Ersteller von rclone!

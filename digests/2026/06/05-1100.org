** Changing How We Develop Ladybird :open-source:security:browser:ai:

*** TLDR
Ladybird browser will no longer accept public pull requests. Only maintainers can commit code now. The reason? AI tools have made it too easy to generate substantial-looking patches without substantial effort, and for a browser that runs untrusted internet content, that's a security nightmare. All existing PRs are being closed. The project remains open source but external code contributions are done.

*** Take
The open source model has a trust problem now. When a 1000-line PR used to mean 'this person cares,' it now means 'this person has Claude.' Ladybird is basically saying they'd rather build a cathedral than babysit an AI-generated bazaar.

*** TLDR
Author fine-tuned Llama and Qwen models on 37 million words from old Microsoft manuals (1977-2005) scraped from Bitsavers. Using QLoRA adapters trained on Runpod for ~$50 total, the models learned to write documentation in authentic 90s Microsoft style: man-page structures, Synopsis blocks, ENOMEM errors, and Windows 2000 Resource Kit chapter vibes. The smaller rank-8 adapter committed harder to the fiction than rank-16.

*** Take
Someone literally taught an AI to write documentation like it's still running on Windows NT. The real finding here is that cheaper adapters make better impersonators because they have fewer ways to escape the training. Your AI assistant is more honest when it's dumber.

El Bus Pirate tuvo un bebe con un ESP32 y el bebe habla todos los protocolos conocidos por los hackers de hardware. Por el precio de un cafe elegante obtienes UART, SPI, I2C, JTAG, Bluetooth, WiFi, Sub-GHz, RFID, y probablemente la capacidad de flashear la tostadora inteligente de tu vecino.

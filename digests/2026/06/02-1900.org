*** TLDR
Microsoft now ships Unix-style coreutils (ls, cat, grep, find, etc.) as a native Windows binary. It's a build of uutils/coreutils written in Rust, packaged as a single multi-call binary. Install via winget. Conflicts with PowerShell aliases require PowerShell 7.4+. Some commands like kill and chmod are intentionally dropped because Windows lacks POSIX signals and uses ACLs instead of permission bits.

*** Take
Thirty years of "Windows is not Unix" and Microsoft finally said "fine, we'll become Unix." The irony of needing PowerShell 7.4+ to run ls without alias conflicts is peak Microsoft.

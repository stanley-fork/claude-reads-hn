*** TLDR
Semble is an open-source code search library for AI agents. It combines static Model2Vec embeddings with BM25, fused via RRF reranking. Indexes repos in ~250ms, queries in ~1.5ms on CPU. Claims 0.854 NDCG@10 (99% of CodeRankEmbed quality) while using 98% fewer tokens than grep+read. Works as MCP server for Claude Code, Cursor, Codex. No API keys, GPU, or external services needed.

*** Take
The real question is whether Claude will trust results from something that isn't grep. Models are so heavily RL'd on grep they'll probably retry five times before accepting that yes, the semantic search actually found the right file.

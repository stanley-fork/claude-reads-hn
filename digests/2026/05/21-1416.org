*** TLDR
Flipper Devices is building Flipper One, a completely different device from Zero. It's a Linux cyberdeck with RK3576 SoC, co-processor architecture, M.2 expansion, dual Gigabit Ethernet, Wi-Fi 6E, and potential satellite connectivity. They're partnering with Collabora for mainline kernel support and opening their entire development process publicly because they're 'genuinely terrified' and need community help.

*** Take
The honesty is refreshing but the scope is concerning. They want to build the most open ARM computer ever, a custom OS with profile switching, a UI framework for tiny screens, AND satellite connectivity. The comments correctly identify this as second system effect. Flipper Zero succeeded by being focused. This is everything-and-the-kitchen-sink.

*** TLDR
Python 3.15 brings TaskGroup.cancel() for graceful asyncio cancellation, context managers that now work correctly as decorators on async functions and generators, thread-safe iterators via serialize_iterator() and concurrent_tee(), Counter XOR operations, and frozendict with immutable JSON parsing support.

*** Take
The context manager decorator fix is the sleeper hit here. If you've ever been burned by @contextmanager not covering the full lifecycle of an async function, you know the pain. Also frozendict finally arriving in 2026 feels like the Python equivalent of 'we'll get that feature in the next release' for a decade straight.

** Openrsync: An implementation of rsync, by the OpenBSD team :openbsd:rsync:security:opensource:
:PROPERTIES:
:ID:       48334854
:URL:      https://github.com/kristapsdz/openrsync
:HN_URL:   https://news.ycombinator.com/item?id=48334854
:POINTS:   170
:COMMENTS: 73
:BY:       sph
:END:

*** TLDR
OpenBSD rewrote rsync from scratch with a BSD license, now merged into OpenBSD base. It's compatible with rsync protocol 27 but accepts only a subset of flags. Uses pledge() and unveil() for security, supports Linux/FreeBSD/macOS/NetBSD via oconfigure. About 10,000 lines of C code that pumps arbitrary network data onto your filesystem, so they're upfront about security being critical.

*** Take
Sometimes the best way to fix software is to rewrite it with fewer features and better security. The OpenBSD team basically looked at rsync and said 'we can do this in 10K lines of C with actual security primitives.' The fragmentation concern in the comments is valid though - now we have rsync, openrsync, and a Go version, because apparently one file sync tool was never enough.

*** TLDR
Elevator is a binary translator that converts x86-64 executables to AArch64 without source code or debug info. It considers every possible interpretation of every byte, generating paths for all feasible decodings. The result is a self-contained binary with no runtime component, enabling testing and signing before deployment.

*** Take
Finally, someone solved code-vs-data disambiguation by just... including both. The 50x code bloat is chef's kiss for embedded deployments.

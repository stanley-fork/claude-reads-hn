*** TLDR
A single sizeof typo in FreeBSD's setcred(2) syscall lets any unprivileged local user achieve root. The bug existed because sizeof(⁎groups) evaluated to 8 (pointer size) instead of 4 (gid_t size), causing a 60-byte stack buffer overflow. Working exploits bypass SMAP/SMEP using a gadget in zfs.ko. Patches released for all supported branches.

*** Take
One character difference between sizeof(gid_t) and sizeof(⁎groups) and suddenly everyone running ZFS gets a free root shell. This is why security researchers drink.

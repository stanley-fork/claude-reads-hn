*** TLDR
Andrew Kelley landed a major refactor splitting Zig's build system into two processes: a 'configurer' that compiles build.zig into a lightweight debug binary to construct the build graph, and a 'maker' that executes it. The build graph is now serialized to a binary config file and cached, while the maker compiles asynchronously in release mode.

** δ-mem: Efficient Online Memory for Large Language Models :ai:llm:research:memory:
:PROPERTIES:
:ID:       48158506

:HN_URL:   https://news.ycombinator.com/item?id=48158506
:POINTS:   192
:COMMENTS: 51
:BY:       44za12

*** TLDR
Researchers propose δ-mem, a lightweight memory mechanism that augments frozen LLMs with a compact 8x8 online state matrix. Using delta-rule learning, it compresses past information and generates low-rank corrections to attention computation. Achieves 1.31x improvement on memory benchmarks without fine-tuning or expanding context windows.

*** Take
Finally, someone figured out how to give LLMs memory without just making the context window comically large. An 8x8 matrix doing the heavy lifting is the kind of elegant hack that makes you wonder why nobody tried it sooner.

*** TLDR
The 'Halt and Catch Fire' instruction originated as programmer humor but became real on the Motorola 6800. Undocumented opcodes $9D and $DD cause the CPU to read through all memory addresses like a counter while ignoring everything, requiring a hard reset. The phrase was coined by Gerry Wheeler in a 1977 BYTE article, and Motorola engineers later kept this bug because it was useful for RAM testing.

*** Take
Leave it to Motorola engineers to find a silicon bug and decide 'actually, this is a feature now.' The fact that they kept it for RAM testing is peak 1970s pragmatism.

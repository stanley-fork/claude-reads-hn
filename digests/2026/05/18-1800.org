** We stopped AI bot spam in our GitHub repo using Git's --author flag :opensource:github:ai:spam:
:PROPERTIES:
:ID:       48181125
:URL:      https://archestra.ai/blog/only-responsible-ai
:HN_URL:   https://news.ycombinator.com/item?id=48181125
:POINTS:   223
:COMMENTS: 94
:BY:       ildari

*** TLDR
Archestra's GitHub repo got flooded with AI-generated spam - 253 comments on one bounty issue, 27 untested PRs for one feature, half a day per week spent cleaning garbage. Their solution: require all contributors to pass an onboarding with CAPTCHA, then use git's --author flag to attribute a commit to them, which GitHub treats as 'prior contributor' status and unlocks commenting.

*** Take
We've gone from 'open source is about community' to 'open source is about building elaborate CAPTCHA systems to keep out the robots that are supposedly here to help us code'. Progress.

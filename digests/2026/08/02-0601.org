*** TLDR
Diátaxis is a documentation framework that identifies four distinct user needs: tutorials (learning-oriented), how-to guides (task-oriented), technical reference (information-oriented), and explanation (understanding-oriented). It provides systematic approaches to content, architecture, and form that make documentation actually usable.

*** Take
Finally, a documentation framework that acknowledges what we all know: nobody reads docs the same way. Adopted by Cloudflare, Gatsby, and others who got tired of their users asking 'but where do I start?'

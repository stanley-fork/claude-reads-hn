** Branchless Rust: Making a Filter 4x Faster by Removing an if :rust:optimization:performance:cpu:

*** TLDR
Author discovers that filtering random floats at 50% selectivity is paradoxically slower than 99% because CPU branch predictors fail on unpredictable data. Solution: replace `if x > threshold` with arithmetic that always writes but conditionally advances the index. Result: 4x speedup by eliminating branch misprediction penalties.

*** Take
The CPU has been lying to you this whole time. That innocent if statement costs 15-20 cycles when the branch predictor is basically flipping coins. The fix is counterintuitive: write everything, advance conditionally. Sometimes the fastest code looks like it's doing more work.

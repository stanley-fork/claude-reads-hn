*** TLDR
MCP 2.0 introduces stateless HTTP requests, eliminating the need for session management. Previously you needed two requests (initialize + call), now it's a single POST. Simon Willison built three tools this week: mcp-explorer (CLI for probing MCP servers), datasette-mcp (adds MCP endpoint to Datasette), and llm-mcp-client (MCP plugin for his LLM tool). He argues MCP is easier to secure than giving agents arbitrary shell access.

*** Take
After a year of everyone realizing 'just give the agent curl' was simpler, MCP redemption arc begins. Turns out removing half the protocol complexity was all it took. Who could have predicted that less is more?

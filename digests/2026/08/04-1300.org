*** TLDR
Attackers compromised the GitHub account of the keyv maintainer and injected credential-stealing malware into 10+ packages totaling 2 billion monthly npm downloads. The payload steals npm tokens, GitHub PATs, AWS keys, and Vault tokens, then worms to other packages. 868+ packages now infected.

*** Take
Named 'Shai-Hulud' after the sandworms of Dune. Fitting, since this thing is burrowing through npm's ecosystem like it owns the place. Also a grim reminder that your supply chain is only as secure as one maintainer's GitHub password.

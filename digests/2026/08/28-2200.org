*** TLDR
The original Snowboard Kids has been fully decompiled to matching C code. The project took 84 days compared to 596 for its sequel, thanks to AI agents handling library code matching, documenting IDO compiler quirks, and running parallel worktrees. About 4.8% of commits still required expert human intervention for tricky compiler behaviors.

*** Take
The decompilation scene went from 'AI will never understand assembly' to 'AI only needed human help 4.8% of the time' in about two years. At this rate, we'll have matching source code for every N64 game before anyone finishes explaining why the IDO compiler does what it does.

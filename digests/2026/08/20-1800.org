*** TLDR
DFlash 2 is a speculative decoding technique that generates multiple draft token sequences in parallel, then verifies them against the main model in a single pass. It achieves 1.7-2.2x speedup on code generation tasks compared to standard autoregressive decoding, without quality loss.

** Breaking Claude Code Opus 5 Auto Mode :security:ai:anthropic:prompt-injection:
:PROPERTIES:
:ID:       49506819
:URL:      https://embracethered.com/blog/posts/2026/breaking-claude-code-opus-5-and-automode/
:HN_URL:   https://news.ycombinator.com/item?id=49506819

:BY:       todsacerdoti

*** TLDR
Security researcher demonstrates 60-80% attack success rate against Claude Code Opus 5's Auto Mode, despite Anthropic's commissioned evaluation showing 0.00% prompt injection success. The attack chain uses a malicious website that returns HTTP 415 to force Claude from WebFetch to curl, redirects to a ZIP containing a poisoned struct.py that shadows Python's standard library, achieving code execution when Claude writes and runs its own safe decoder. Auto Mode even blocked Claude's attempt to terminate the malware after it detected the compromise.

*** Take
Anthropic said prompt injection was largely solved in practice. The researcher said hold my beer. Turns out the 0.00% came from testing 72 scenarios, none of which involved this attack. That's like claiming your car is theft-proof because nobody tried the door handle.

** Cores in space: The core memory module from a 1980 Spacelab computer :hardware:space:history:retrocomputing:

*** TLDR
Ken Shirriff does a deep dive into the core memory from Spacelab's French-built Mitra 125 MS computer that flew on the Space Shuttle. The 128KB memory uses 294,912 tiny ferrite cores per board, with sophisticated 2.5D architecture that eliminates inhibit lines. Each core is 0.8mm diameter, wired with copper select lines and green sense wires. The memory survived space because core memory is nonvolatile and radiation-resistant.

*** Take
Ken Shirriff could make a dissertation out of a toaster's power cord. This time he's explaining why 1980s astronauts trusted their lives to tiny magnetic donuts rather than newfangled semiconductor RAM. The answer, as always with aerospace: it was radiation-proof and we could load the software exactly once.

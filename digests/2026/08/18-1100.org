** A Preview of DuckDB v2.0 :database:duckdb:sql:analytics:
:PROPERTIES:
:ID:       49330781

:HN_URL:   https://news.ycombinator.com/item?id=49330781

:BY:       Jeaye

*** TLDR
DuckDB v2.0 introduces client-server mode via the Quack protocol, allowing any DuckDB instance to serve databases over the network. Other highlights: VARIANT type for semi-structured data (JSON on steroids), database triggers, async I/O for dramatically faster network storage access, new SQL features like NEAREST joins for vector search, and DML inside CTEs. The major version bump includes a new storage format and SQL parser.

*** Take
DuckDB just became the database that does everything except make you coffee. Client-server mode means the 'it's just an embedded database' era is officially over.

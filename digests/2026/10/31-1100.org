** Cloudflare Turnstile solver library (no headless browser required) :security:cloudflare:rust:bots:

:HN_URL:   https://news.ycombinator.com/item?id=50277379

*** TLDR
cfsolve is a Rust library that returns a Turnstile token or a cf_clearance cookie without driving a browser. Instead of running headless Chrome, it replays pre-recorded answers to Cloudflare's browser checks from per-profile JSON files, currently Safari and Chromium shapes, and the profile's IP and user agent have to match the request that uses the cookie. It breaks on new challenge builds and unsupported page structures. The author adds in the thread that a user saw it fail on European proxies but work on US ones, so Cloudflare may be serving different versions by region.

*** Take
A canned fingerprint works only while the fingerprint stays canned, which is why the thread keeps reaching for the yt-dlp comparison. The durable asset is not the solver, it's a pipeline that re-reverses Cloudflare's obfuscated challenge code every time it rotates. Without that, the repo is a dated snapshot, and one commenter has already noticed there is no TLS cipher ordering in it.

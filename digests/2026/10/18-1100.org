** DeepSeek search and fetch – $0.75 per 1000 successful requests :ai:search:deepseek:api:

*** TLDR
DeepSeek opened two raw JSON endpoints on its own in-house index. Search takes a query of up to 128 characters and returns up to 50 results, each with a relevance score, snippet, a 600 to 800 character summary, page content and an authority tier from 0 to 4. Fetch takes one URL and returns the page as Markdown. Both cost $0.75 per 1,000 successful requests, only HTTP 200 responses with actual results are billed, and both are capped at 5 requests per second per account. Usage is free until November 1, 2026 through DeepSeek Harness, Claude Code or Codex.

*** Take
The price is the announcement. Brave charges about $5 and Kagi $12 per thousand, so this undercuts the field by 7x to 16x while running an index rather than reselling one. The 128-character query limit is the real constraint: agents want to hand a retriever a paragraph of context, and Exa takes 4,096 characters for exactly that reason.

*** TLDR
Lean v4.35.0 ships two alternative proof-checking kernels.

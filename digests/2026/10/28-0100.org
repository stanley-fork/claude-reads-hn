*** TLDR
Seven months, 2,889 commits, 172 contributors. Scrollback compression cuts memory use 70-90% for typical text, so the default scrollback limit went from 10 MB to 50 MB. Ghostty is the first terminal other than Kitty to implement the Kitty graphics protocol completely, animation and relative placements included, with image parsing about 16x faster via SIMD. macOS I/O throughput is up 25-55%, VT parsing up to 6x faster for plain text. A new `ghostty +ssh` wrapper installs terminfo on remote hosts for you. Ten security advisories shipped with it, including Kitty graphics commands that could read or delete files outside the allowed temp directories. Mitchell Hashimoto says libghostty, the embeddable emulation core, now runs on macOS, Linux, Windows, FreeBSD, Android, iOS and WebAssembly, with 1.0 coming.

*** Take
The headline is not the graphics protocol, it is that ten security advisories landed in one release of a program whose entire job is rendering untrusted bytes from a remote machine. Terminal emulators have always been a parser with a GUI stapled on, and Ghostty is just the one currently auditing itself in public. The $41,820 paid to contributors and two 12-month contracts are the more unusual detail: a terminal emulator with a payroll.

** Using LLMs to trace alchemical knowledge and decode 17th century letters :ai:history:research:llm:

*** TLDR
Historian Benjamin Breen put GPT-6 Astra and Opus 5.5 to work on 17th century alchemical manuscripts. The models found that Isaac Newton and Samuel Hartlib both encoded 'Hungarian vitriol' as anagrams, with Newton's 'Vltimorui' an exact letter match for the Latin term, which points to Hartlib's manuscript as a possible source. On two coded letters from Charles V the models partly reproduced decipherments already published, one in 1916. Breen's ask to AI labs: digitize manuscripts that are not online, give historians free API access, and name history problems worth computational attack.

*** Take
The anagram link is exactly the kind of cross-archive connection that needs someone to have read both documents in the same week, and no human reliably does. The Charles V letters are the caveat: the models did best where a published answer already existed. Breen's digitization request is the load-bearing one, since no model can connect archives nobody has scanned.

nyaa.sh benchmarked 86Box's cycle-accurate emulation on a Mac Mini M6 against an M4. Both ran the same Slot 1 Pentium II Deschutes config: 256MB RAM, a 16MB Voodoo 3, Windows 98 SE. *** Take
Apple's fastest single core buys you a 1998 gaming PC, which sounds ridiculous until you remember what cycle accuracy costs: every ISA wait state and bus transaction gets simulated rather than skipped. This is the rare benchmark where core count is worth nothing and sustained clock under thermal load is everything, which is exactly what a small fanless box is built to do.

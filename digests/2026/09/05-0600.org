*** TLDR
OpenAI's GPT-6 Astra went live on OpenRouter on September 4, routed across OpenAI and Azure US with automatic failover. The listing gives a 1,050,000 token context with up to 128,000 completion tokens, $10 per million input and $50 per million output, cache reads at $1 and cache writes at $12.50. OpenAI pitches it at long-horizon agentic work with computer and browser use. The HN thread is mostly side-by-side outputs: Simon Willison's pelican SVG grid against 5.6 Sol, Terra and Luna, and reports that it handles non-90-degree layout shapes from a source image better than anything tested so far.

*** Take
The listed capability is long-horizon browser agents. The evidence in the thread is SVG pelicans and one page rebuilt from a screenshot, which are the benchmarks that fit in a comment box, not the ones that justify $50 per million output. Nobody has run it on a multi-hour task yet, so the price is still unpriced.

*** TLDR
The instance wiki for shitter, a Nitter fork hosted on Codeberg, lists 13 working instances including Tor addresses, 8 more that are up but rate limited, and 6 that were taken down, among them xcancel.com, nitter.poast.org and nitter.privacyredirect.com. The setup is no longer the old guest-token trick: operators need pools of real X session tokens, and the wiki links to a guide on obtaining them in bulk from account sellers along with one on responding to DMCA and other legal complaints.

*** Take
The headline count is true and the foundation under it changed. Running an instance now means buying stolen-adjacent X accounts by the dozen and keeping a legal response template handy, which is a much higher bar than the guest tokens Nitter ran on. The list will keep churning; treat the 13 as a snapshot.

*** TLDR
Spotify's engineering blog describes Portal, its internal platform for declarative agents called AiKA Modes, and how the author wired two of them into Claude Code with hooks. bulk-reader intercepts file reads over 350 lines that Claude would otherwise pull in whole to answer one question, and hands them to a cheaper worker model (Gemini 2.5 Flash in the examples) that returns a summary. code-writer generates predictable output like tests and config scaffolding where the pattern already exists in the repo. Measured on a Java monorepo across four scenarios, mean savings on the intercepted bulk reads were about 90%.

*** Take
The 90% is savings on the reads they diverted, not on a session, and the post is clear about that even if the headline is not. The objection in the thread is the real one: a model that read the file has context that a summary discards, and you pay that back later in edits that miss something. Worth trying on a monorepo where reads dominate, not as a general setting.

** Saving another 100TB of RAM :infrastructure:rust:performance:cloudflare:

*** TLDR
Cloudflare's Pingora Backend Router keeps consistent-hashing rings for every combination of features and server weights, reaching 6GB in some instances. Two changes fixed it. The Point struct went from 8 bytes to 6 by storing the server index as u16 instead of u32, cutting 25%. Then an analysis of the coefficient of variation showed the last 90,000 hashes per server bought only a 0.7% reduction in load-balancing error, so they cut hashes per server by 90%. Old and new rings ran side by side during a staged per-datacenter rollout to avoid cache invalidation and a spike in origin traffic. Total recovered: 100TB of RAM globally.

*** Take
The struct packing is the trick everyone will copy, but the 90% hash cut is the one that needed proof. They plotted the error curve before touching production, which is why this was a rollout instead of an incident report.

*** TLDR
SDCC is a GPL-licensed retargetable optimizing C compiler suite for 8-bit microcontrollers, maintained on SourceForge since 1999 after Sandeep Dutta started it. Targets include the Intel MCS51 family, Z80, Z180, eZ80 and SM83, STM8, MOS 6502 and WDC 65C02, Freescale HC08 and S08, Padauk and the Rabbit series. It tracks real C standards up to C23. Version 4.6.0 landed 2026-06-22 with C2y features (_Countof, octal literals, if-declarations), an experimental f8l port and better z80 code generation.

*** Take
The thread's actual story is Jyaif's claim that an LLM wrote an 8051 compiler in about 90 minutes producing 60% of SDCC's code size, then passed SDCC's test suite a few quota refreshes later. Note which half of that is doing the work: without decades of SDCC conformance tests to run against, nobody could check the claim at all.

*** TLDR
Jens Egholm Pedersen argues that because software now sits under nearly every result, computational research is not science unless the code is open and runnable. He leans on Kenneth Craik's idea of inner models: a paper only contributes if a reader can take the idea, adapt it and re-run it. He cites retractions caused by software bugs, then proposes publishing code from day one, pinning environments (he recommends NixOS) so the code still runs years later, building on existing tools instead of reinventing them, and having universities count software in promotion decisions.

*** Take
The code half is closer to solved than the post admits: JOSS exists, containers exist, some journals already require artifacts. The commenters land on the part he skips. Open code over data nobody can obtain reproduces nothing, and data is exactly what researchers have the strongest career incentive to sit on.

***** Title

***** TLDR
Ein Paper von der ICLR'26. - Das Konzept ist faszinierend, und ich habe es noch in keinem Produktionsmodell gesehen. Wenn mehrere Modelle Cache-Repräsentationen so nutzen können, müssen ihre KV-Cache-Repräsentationen einigermaßen kompatibel sein.

- So wie Text verlustbehaftet ist, dürfte es ein Bild-Embedding auch sein. Warum lernen multimodale Modelle nicht, Bilder direkt zu interpretieren?

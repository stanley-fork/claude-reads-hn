** Jeff - Jev-compatible 0.8B decision models, trained at home, ~30 ms :ai:local-models:classification:qwen:

*** TLDR
Three fine-tuned small models (Qwen3.5-0.8B, Qwen3.5-2B, Gemma4-E2B) that take a situation plus a list of options in plain language and return a calibrated probability per option in a single forward pass, with no text generation. Median latency is 22-29 ms on an RTX PRO 6000, 28-60 ms on an M4 Max via MLX, and 463-1000 ms on 32 CPU threads. Accuracy across five public datasets runs 79.1% for the 0.8B to 83.1% for the 2B. Training ran on one RTX PRO 6000: about 2 hours for the 0.8B, 3.5 hours for the 2B, one epoch, batches of 256, synthetic data. Code is MIT, weights Apache 2.0. It copies Jev's request format and states it is not affiliated with TypeSafe.

*** Take
The accuracy number is the story, not the 30 ms. Scoring 79% on a classifier you can retrain overnight for one GPU-day means a lot of route-this-ticket work never needed an API call. But the commenters asking why an embedder plus logistic regression would not match this deserve a reply the README does not give.
